## Requirements

- macOS

- Swift Package Manager

## Commands

```sh
cd ~/Developer/AI-Brain/02-Projects/skill-dumpster/source
swift test
Scripts/generate_app_icon.sh
Scripts/package_app.sh
```

The packaging script creates:

```sh
build/Skill Dumpster.app
```

The packaged app Info.plist is generated by `source/Scripts/package_app.sh`; version metadata is intentionally kept there because this project uses a lightweight SwiftPM packaging flow instead of an Xcode project.

Generated build directories are intentionally ignored by git-style tooling:

- `.build/`
- `build/`

They can be recreated from source at any time.
